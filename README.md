# 📚 Yuri-Codex

A personal knowledge vault for books, literature, LLMs, coding, science, philosophy, geography, machines, motorsport, and developer resources.

## What it stores

- 📖 Books and literature
- 🤖 LLM / SLM resources, papers, models and datasets
- 💻 Coding and computer science references
- 🛠️ Developer tools and platforms
- ☁️ Hosting and deployment services
- 🧠 Neuroscience and computational intelligence
- ⚙️ Hardware, electronics and machines
- 🏎️ Motorsport and engineering
- 🌍 Geography
- 🎮 Game development
- 🧠 Philosophy, history and science

## Run it

Yuri-Codex is a static HTML app designed for GitHub Pages. No backend or build step is required.

Open `index.html` locally or enable GitHub Pages for the repository's `main` branch.

## Data

Custom resources are stored locally in the browser with `localStorage`. Use **Export** to back up the collection as JSON.
