# 📚 Yuri-Codex

A personal knowledge vault for books, literature, LLMs, coding, science, philosophy, geography, machines, motorsport, and developer resources.

## What it stores

- 📖 Books and literature
- 🤖 LLM / SLM resources, papers, models and datasets
- 💻 Coding and computer science references
- 🛠️ Developer tools and platforms
- ☁️ Hosting and deployment services
- 🧠 Neuroscience and computational intelligence
- ⚙️ Hardware, electronics and machines
- 🏎️ Motorsport and engineering
- 🌍 Geography
- 🎮 Game development
- 🧠 Philosophy, history and science

## Experimental Lab 🧪

The second-edition playground lives at [`experiments/index.html`](experiments/index.html). It is intentionally separate from the main archive so visual experiments can be pushed hard without turning the core Codex into a fragile demo.

Current experiments include:

- React Three Fiber + Three.js 3D scene
- ShaderGradient procedural animation
- Liquid Glass JS WebGL glass surface
- Independent liquid-logo-style canvas shader experiment

The lab loads its experimental dependencies from browser CDNs and does not add a build system to the main Codex.

## Run it

Yuri-Codex is a static HTML app designed for GitHub Pages. No backend or build step is required.

Open `index.html` locally or enable GitHub Pages for the repository's `main` branch. The experimental playground can be opened directly at `experiments/index.html`.

## Data

Custom resources are stored locally in the browser with `localStorage`. Use **Export** to back up the collection as JSON.
